## 설명

```text
WLT는 Windows용 경량 터미널입니다. 로컬 셸과 원격 Linux 서버(SSH)를 탭과 분할 화면으로 함께 쓰고, 서버 파일 탐색기와 편집기, 포트 포워딩까지 한 창에서 처리합니다.

■ 로컬 셸과 SSH를 한 곳에서
PowerShell, 명령 프롬프트, WSL, Git Bash를 자동으로 찾아 목록에 보여 줍니다. SSH 서버는 비밀번호, 개인 키(ed25519 · RSA · ECDSA), SSH 에이전트로 접속할 수 있습니다.

■ VS Code처럼 탭을 끌어 화면 분할
탭을 끌어 상하좌우로 화면을 나누고, 연결을 유지한 채 다른 창으로 옮길 수 있습니다. 탭 복제 · 잠금 · 이름 변경, 탭별 글꼴 확대를 지원합니다.

■ 서버 파일을 내 PC처럼
SFTP 파일 탐색기로 서버 파일을 관리하고, Windows 탐색기에서 끌어다 놓아 바로 업로드합니다. 파일을 더블클릭하면 내장 편집기(80여 개 언어 문법 강조, UTF-8/EUC-KR 유지)로 열고, 저장하면 서버에 자동으로 올라갑니다.

■ 폴더 전체에서 글자 찾기
대소문자 · 단어 단위 · 정규식, 포함/제외 패턴으로 로컬과 서버 폴더를 검색합니다. 서버에서는 grep으로 빠르게 찾고, 결과를 누르면 편집기에서 해당 줄이 열립니다.

■ 어제 하던 작업 그대로
앱을 종료할 때 열려 있던 탭을 기록해 두고, 다음에 클릭 한 번으로 같은 셸 · 서버에 다시 연결해 마지막 폴더로 돌아갑니다.

■ 포트 포워딩
로컬(-L), 원격(-R), 동적 SOCKS5(-D) 포워딩을 세션마다 저장해 두고 접속할 때 자동으로 엽니다.

■ 안전한 비밀번호 보관
비밀번호와 키 암호는 Windows 자격 증명 관리자에만 저장합니다. 처음 접속한 서버의 키를 기억해 두고, 키가 바뀌면 접속 전에 경고합니다.

■ 개인정보를 수집하지 않습니다
회원 가입, 광고, 사용 통계 수집이 없습니다. WLT는 사용자가 접속한 서버와만 통신합니다.

※ 앱 화면은 한국어로 제공됩니다.
```

## 제품 기능 (한 칸에 하나씩, 9개)

```text
로컬 셸 자동 감지: PowerShell · 명령 프롬프트 · WSL · Git Bash
SSH 접속: 비밀번호 · 개인 키(ed25519 · RSA · ECDSA) · SSH 에이전트
탭을 끌어 상하좌우 화면 분할, 연결을 유지한 채 탭 이동
SFTP 파일 탐색기: 업로드 · 다운로드 · Windows 탐색기에서 끌어다 놓기
내장 편집기로 서버 파일을 바로 편집하고 저장 시 자동 업로드
폴더 전체 파일 내용 검색 (정규식 · 포함/제외 패턴, 서버는 grep 사용)
세션 히스토리: 종료할 때 열려 있던 탭과 작업 폴더로 복귀
포트 포워딩: 로컬(-L) · 원격(-R) · 동적 SOCKS5(-D)
비밀번호는 Windows 자격 증명 관리자에만 저장, 서버 키 확인(TOFU)
```
