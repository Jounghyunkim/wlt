# Store 스크린샷 촬영 가이드

Store 규칙: PNG, 1366×768 이상 (1920×1080 권장), 최소 1장, 4장 이상 권장, 실제 앱 화면.

## 촬영 방법

1. WLT를 실행하고 아래 장면을 준비합니다.
2. 다른 터미널(VS Code 등)에서 실행합니다:

   ```powershell
   powershell -ExecutionPolicy Bypass -File store\capture-screenshot.ps1 -Name 01-split
   ```

   WLT 창이 화면 왼쪽 위로 옮겨지고 정확히 1920×1080으로 바뀐 뒤, 3초 후 `store\screenshots\01-split.png`로 저장됩니다.
   화면이 1920×1080보다 작으면 `-Width 1366 -Height 768`을 붙이세요.
   메뉴를 열어 둔 장면은 `-Delay 6`으로 시간을 늘린 뒤 그 사이 메뉴를 여세요.

## 촬영 전 확인 (보안)

- 실제 서버 주소, 사용자 이름, 회사 서버 이름이 **화면에 보이지 않게** 하세요. 시연용 세션 이름(예: `web-server`, `dev-box`)과 테스트 서버를 쓰는 것이 좋습니다.
- 터미널 기록에 비밀번호, 토큰, 사내 경로가 남아 있지 않은지 확인하세요.
- 세션 목록에 업무용 세션이 있다면 잠시 이름을 바꾸거나 시연용 세션만 남기세요.
- 로컬 탐색기는 기본으로 홈 폴더(`C:\Users\<사용자 이름>`)를 보여 줍니다. Windows 사용자 이름과 개인 폴더 목록이 드러나니, 시연용 폴더(예: `D:\demo`)로 옮긴 뒤 촬영하세요.

## 추천 장면 (순서대로 6장)

| 파일 | 장면 | 보여 줄 것 |
| --- | --- | --- |
| `01-split` | **분할 화면** | 왼쪽 로컬 PowerShell, 오른쪽 위 SSH 서버(`htop` 또는 `ls -la --color`), 오른쪽 아래 다른 서버 |
| `02-explorer` | **SFTP 파일 탐색기** | 사이드바에 서버 폴더 트리, 아래 전송 목록에 업로드 진행 중 항목 |
| `03-editor` | **편집기** | 서버의 설정 파일(예: `nginx.conf`)을 편집기 탭으로 연 모습, 문법 강조가 보이게 |
| `04-search` | **파일 내용 검색** | 서버 폴더에서 검색어를 찾은 결과 목록 + 편집기에 해당 줄 |
| `05-session` | **SSH 세션 설정** | 세션 다이얼로그(인증 방식 · 포트 포워딩 탭), 시연용 주소로 |
| `06-themes` | **테마** | 밝은 테마나 배경 그림 테마를 적용한 탭, 또는 설정 다이얼로그 |

팁:

- 첫 장이 Store 목록 맨 앞에 크게 나옵니다. 가장 WLT다운 장면(분할 화면)을 첫 장으로 두세요.
- 터미널 글꼴을 조금 키우면(`Ctrl`+스크롤) Store의 작은 미리 보기에서도 잘 읽힙니다.
- 마우스 포인터는 캡처되지 않습니다.

## 올리기

Partner Center → Store 목록 → 한국어(한국) → 스크린샷 → 데스크톱에 `store\screenshots\*.png`를 순서대로 올립니다.
각 스크린샷에는 짧은 설명(캡션)을 달 수 있습니다:

| 파일 | 캡션 |
| --- | --- |
| `01-split` | 로컬 셸과 SSH 서버를 한 화면에 |
| `02-explorer` | 서버 파일을 끌어다 놓아 업로드 |
| `03-editor` | 서버 파일을 바로 편집, 저장하면 자동 업로드 |
| `04-search` | 폴더 전체에서 글자 찾기 |
| `05-session` | 비밀번호 · 개인 키 · 에이전트 인증과 포트 포워딩 |
| `06-themes` | 테마 10종, 탭마다 다른 테마 |
