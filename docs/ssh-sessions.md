# 2. SSH 세션과 인증

[← 가이드 목차](README.md)

## 세션 관리

사이드바 **터미널** 메뉴의 **SSH 세션** 목록에서 저장한 서버를 관리합니다.

| 하고 싶은 것 | 방법 |
| --- | --- |
| 접속 | 세션을 **더블클릭** (또는 선택 후 Enter) |
| 새 세션 | 사이드바 위쪽 `+` |
| 편집 · 복제 · 삭제 | 세션에 마우스를 올리면 나타나는 ✏️ · 📄 · 🗑 버튼 |
| 검색 | **세션 검색** 칸에 이름, 호스트, 사용자, 그룹 입력 |
| 묶어서 보기 | 세션 편집에서 **그룹**을 입력하면 그룹별로 접고 펼 수 있음 |

세션을 **복제**하면 저장된 비밀번호도 함께 복사되고, **삭제**하면 저장된 비밀번호도 함께 지워집니다.

## 인증 방식 고르기

| 인증 방식 | 이럴 때 | 준비물 |
| --- | --- | --- |
| **비밀번호** | 가장 간단한 방법 | 서버 계정 비밀번호 |
| **개인 키** | 키 파일로 로그인하는 서버 | `~/.ssh/id_ed25519` 같은 키 파일 (암호는 선택) |
| **SSH 에이전트** | 키를 이미 ssh-agent나 Pageant에 등록해 둔 경우 | 실행 중인 에이전트 |

### 비밀번호

- 비밀번호 칸을 **비워 두면** 접속할 때마다 묻습니다.
- 매번 입력하기 번거롭다면 아래의 [비밀번호 저장](#비밀번호-저장-windows-자격-증명-관리자)을 켜세요.

### 개인 키

- **개인 키 경로**에 키 파일 위치를 입력합니다. `~`는 내 사용자 폴더(`C:\Users\<이름>`)를 뜻합니다.
- OpenSSH 형식(ed25519, RSA, ECDSA)과 PEM 형식을 지원합니다.
- 키에 암호가 걸려 있다면 **키 암호**에 입력합니다. 이 암호도 자격 증명 관리자에 저장할 수 있습니다.

### SSH 에이전트

SSH 에이전트는 개인 키를 메모리에 들고 있다가 **대신 서명해 주는 프로그램**입니다. 이 방식을 쓰면 WLT에는 키 파일도 암호도 저장하지 않습니다.

WLT는 다음 순서로 에이전트를 찾습니다.

1. **Windows OpenSSH 에이전트** (ssh-agent 서비스)
2. 없으면 PuTTY의 **Pageant**

에이전트에 등록된 키를 하나씩 서버에 보여 주고, 서버가 받아들이는 키로 로그인합니다.

#### Windows OpenSSH 에이전트 설정 (처음 한 번)

1. **관리자** PowerShell에서 서비스를 켭니다.

   ```powershell
   Set-Service ssh-agent -StartupType Automatic
   Start-Service ssh-agent
   ```

2. 일반 PowerShell에서 키를 등록합니다.

   ```powershell
   ssh-add $HOME\.ssh\id_ed25519
   ssh-add -l   # 등록된 키 확인
   ```

3. WLT 세션의 인증 방식을 **SSH 에이전트**로 바꾸고 접속합니다.

#### Pageant 사용

PuTTY와 함께 설치되는 Pageant를 실행하고, 트레이 아이콘에서 **Add Key**로 `.ppk` 키를 추가하면 됩니다.

#### 에이전트 인증이 실패하면

터미널에 이유가 표시됩니다.

| 메시지 | 해결 |
| --- | --- |
| `OpenSSH agent: not running` | ssh-agent 서비스가 꺼져 있습니다. 위의 설정 1번을 실행하세요. |
| `no keys loaded (ssh-add)` | 에이전트에 키가 없습니다. `ssh-add`로 키를 등록하세요. |
| `the server accepted none of the N key(s)` | 에이전트의 키가 서버의 `~/.ssh/authorized_keys`에 등록되어 있지 않습니다. |

## 비밀번호 저장 (Windows 자격 증명 관리자)

세션 편집 창에서 **"비밀번호를 Windows 자격 증명 관리자에 안전하게 저장"**을 체크하고 저장하면, 다음부터는 비밀번호를 묻지 않고 바로 접속합니다. 접속할 때 나오는 비밀번호 입력 창에서 **"Windows 자격 증명 관리자에 저장"**을 체크해도 됩니다.

### 왜 안전한가요?

- 비밀번호는 WLT 설정 파일이 아니라 **Windows 자격 증명 관리자**에 저장됩니다. 지금 로그인한 Windows 사용자만 쓸 수 있습니다.
- 저장된 비밀번호는 접속하는 순간 프로그램 내부에서만 읽고, 화면에는 다시 표시하지 않습니다. 세션 편집 창에도 "저장됨"으로만 나옵니다.
- 이전 버전에서 저장했던 비밀번호는 WLT를 실행하면 자동으로 자격 증명 관리자로 옮겨지고, 원래 위치에서는 지워집니다.

### 저장된 항목 확인 · 삭제

1. 시작 메뉴에서 **자격 증명 관리자**를 검색해 실행합니다. 또는 `Win + R` → `control /name Microsoft.CredentialManager`
2. **Windows 자격 증명**을 선택합니다.
3. **일반 자격 증명**에서 `WLT/ssh/<세션 번호>/password` 항목을 찾습니다. 키 암호는 `…/passphrase`입니다.
4. 항목을 펼쳐 **제거**를 누르면 삭제됩니다. 다음 접속 때 WLT가 비밀번호를 다시 묻습니다.

명령어로 확인할 수도 있습니다.

```powershell
cmdkey /list | Select-String "WLT/ssh" -Context 0,2
```

### 저장한 비밀번호 바꾸기 · 지우기

- **바꾸기**: 세션 편집 창의 비밀번호 칸에 새 비밀번호를 입력하고 저장합니다. 칸을 비워 두면 기존 비밀번호가 그대로 유지됩니다.
- **지우기**: 세션 편집 창에서 저장 체크를 해제하고 저장합니다.

## 서버 키 확인 (보안)

처음 접속하는 서버의 키는 `%APPDATA%\com.wlt.terminal\known_hosts`에 저장됩니다. 이후 접속할 때 서버 키가 달라졌다면 접속을 거부하고 빨간 경고를 표시합니다.

```text
@@@ WARNING: REMOTE HOST IDENTIFICATION HAS CHANGED! @@@
```

서버를 새로 설치했거나 키를 바꾼 것이 확실할 때만, 경고에 표시된 줄을 `known_hosts` 파일에서 지우고 다시 접속하세요. 그렇지 않다면 누군가 중간에서 접속을 가로채는 중일 수 있으니 서버 관리자에게 확인하세요.
