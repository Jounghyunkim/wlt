# 4. 탭과 화면 분할

[← 가이드 목차](README.md)

## 탭 기본 조작

| 하고 싶은 것 | 방법 |
| --- | --- |
| 새 탭 | 탭 줄의 `+` → SSH 세션 또는 로컬 셸 선택 (사이드바와 같은 순서) |
| 새 로컬 터미널 (기본 셸) | `Ctrl+Shift+T` |
| 탭 닫기 | 탭의 X, **가운데 클릭**, 또는 `Ctrl+Shift+W` |
| 다음 / 이전 탭 | `Ctrl+Tab` / `Ctrl+Shift+Tab` |
| 탭 순서 바꾸기 | 탭을 끌어 원하는 위치에 놓기 |
| 다시 연결 | 종료된 탭에서 **Enter**, 또는 탭 우클릭 → **다시 연결** |

## 탭 우클릭 메뉴

| 메뉴 | 설명 |
| --- | --- |
| **이름 변경** | 탭 이름을 바꿉니다. 탭 이름을 **더블클릭**해도 됩니다. Enter로 저장, Esc로 취소 |
| **탭 잠금 / 잠금 해제** | 실수로 닫히지 않게 잠급니다 (아래 참고) |
| **탭 테마** | 이 탭에만 다른 테마를 적용합니다 (아래 참고) |
| **모든 텍스트 복사** | 스크롤해서 올려야 보이는 이전 출력까지 전체를 복사 |
| **보이는 화면 복사** | 지금 화면에 보이는 부분만 복사 |
| **모두 선택** | 터미널 전체 선택 (`Ctrl+Shift+A`) |
| **탭 복제** | 같은 셸 / 같은 SSH 서버로 새 탭을 엽니다 |
| **오른쪽에 / 아래에 분할하여 복제** | 복제한 탭을 새 분할 창에 엽니다 |
| **다시 연결** | 연결을 끊고 다시 접속 |
| **다른 탭 닫기** | 같은 창의 나머지 탭을 닫습니다 (잠긴 탭은 제외) |
| **탭 닫기** | 이 탭을 닫습니다. 직접 닫은 탭은 [세션 히스토리](session-history.md)에 남지 않습니다(설정으로 바꿀 수 있음) |

### 텍스트 복사

- 창 너비 때문에 여러 줄로 나뉘어 보이던 긴 줄은 **원래의 한 줄로 합쳐서** 복사합니다.
- 복사가 끝나면 터미널 오른쪽 아래에 "120줄 복사됨" 같은 안내가 잠깐 표시됩니다.
- 메모장 등에 바로 붙여 넣을 수 있도록 Windows 줄바꿈 형식으로 복사합니다.

### 탭 테마

탭 우클릭 → **탭 테마**에서 고른 테마는 **그 탭에만** 적용됩니다. 예를 들어 운영 서버 탭만 밝은 테마나 눈에 띄는 색으로 바꿔 두면, 개발 서버와 헷갈려 잘못된 서버에 명령을 입력하는 실수를 줄일 수 있습니다.

- 메뉴의 각 테마 옆에 배경색과 대표 색 미리보기가 표시되고, 지금 적용된 테마에 ✓가 붙습니다.
- **기본 (설정 테마)**을 고르면 다시 설정의 테마를 따릅니다. 설정에서 테마를 바꾸면, 탭 테마를 따로 정하지 않은 탭만 바뀝니다.
- 탭을 복제하거나, 다른 창으로 옮기거나, [세션 히스토리](session-history.md)에서 다시 열어도 탭 테마가 유지됩니다.
- 터미널 탭에만 있는 메뉴입니다. 편집기 탭은 설정의 테마를 따릅니다(편집기는 모든 탭이 하나의 테마를 함께 씁니다).

### 탭 잠금

잠긴 탭에는 X 대신 노란 🔒 아이콘이 표시되며, 다음 방법으로는 **닫히지 않습니다**.

- X 버튼, 가운데 클릭, `Ctrl+Shift+W`
- 탭 메뉴의 **탭 닫기**, **다른 탭 닫기**

🔒 아이콘을 클릭하거나 탭 메뉴에서 **잠금 해제**를 누르면 풀립니다. 잠긴 탭도 다른 창으로 옮기거나 분할·다시 연결은 할 수 있습니다.

### 탭 복제

복제는 화면 내용을 복사하는 것이 아니라 **같은 설정으로 새 연결을 여는 것**입니다. 로컬 탭은 같은 셸을 새로 실행하고, SSH 탭은 같은 서버에 새로 접속합니다.

## 화면 분할 (VS Code 방식)

여러 터미널을 한 화면에 나란히 볼 수 있습니다.

### 탭을 끌어서 나누기

탭을 끌어 터미널 화면 위로 가져가면, 놓일 자리가 파랗게 표시됩니다.

| 놓는 위치 | 결과 |
| --- | --- |
| 창의 **가장자리** (바깥쪽 25%) — 왼쪽/오른쪽/위/아래 | 그 방향으로 화면이 나뉘고 탭이 새 창으로 이동 |
| 다른 창의 **가운데** | 탭이 그 창으로 이동 |
| 다른 창의 **탭 줄** | 탭이 그 창의 해당 위치로 이동 |

- 탭을 다른 창으로 옮겨도 **셸이나 SSH 연결은 끊기지 않습니다**.
- 창의 마지막 탭을 닫거나 옮기면 그 창은 자동으로 닫힙니다.

### 새 터미널을 바로 분할해서 열기

- 탭 줄 오른쪽 끝의 분할 버튼, 또는 `Ctrl+Shift+\`를 누르면 오른쪽에 새 로컬 터미널이 열립니다.
- 탭 우클릭 → **오른쪽에 / 아래에 분할하여 복제**로 같은 서버를 하나 더 열 수도 있습니다.

### 크기 조절과 포커스

- 창 사이의 **경계선을 끌면** 크기가 바뀌고, **더블클릭하면** 반반이 됩니다.
- `Ctrl+Tab`, `Ctrl+Shift+W` 같은 단축키는 **마지막으로 클릭한 창**에 적용됩니다. 그 창의 활성 탭 위쪽에는 테마 색 막대가 표시됩니다.

## 글꼴 크기

| 방법 | 범위 |
| --- | --- |
| `Ctrl` + **마우스 스크롤** | **현재 탭만** 확대/축소 (8–32px). 오른쪽 아래에 크기가 잠깐 표시됨 |
| `Ctrl` + `=` / `-` | **모든 탭**의 기본 크기 확대/축소 |
| `Ctrl` + `0` | 기본 크기(14px)로 되돌리고, 현재 탭의 개별 크기도 해제 |

탭별 크기는 탭을 다른 창으로 옮겨도 유지되지만, 탭을 닫으면 사라집니다.

## 터미널 안에서의 복사 · 붙여넣기 · 검색

| 동작 | 방법 |
| --- | --- |
| 복사 | 마우스로 선택하면 자동 복사 (설정에서 끌 수 있음), 또는 `Ctrl+Shift+C` |
| 붙여넣기 | `Ctrl+Shift+V` |
| 우클릭 | 선택 영역이 있으면 복사, 없으면 붙여넣기 (PuTTY 방식) |
| 검색 | `Ctrl+Shift+F` — 대소문자 구분, 이전/다음 결과 이동 |
| 파일 경로 입력 | Windows 탐색기에서 파일을 터미널로 끌어다 놓으면 경로가 입력됨 |

## 저장되지 않는 것

분할 배치와 탭 잠금은 WLT를 다시 시작하면 초기화됩니다. 열려 있던 탭은 종료할 때 [세션 히스토리](session-history.md)에 기록되므로(탭 이름·폴더·탭별 글꼴 크기 포함), 다음에 켜서 다시 열 수 있습니다.
