# 5. 파일 탐색기

[← 가이드 목차](README.md)

작업 표시줄의 📄 **탐색기** 아이콘을 누르거나 `Ctrl+Shift+E`를 누르면 사이드바에 파일 탐색기가 열립니다. VS Code의 탐색기처럼 파일과 폴더를 다룰 수 있습니다.

## 어느 컴퓨터의 파일을 볼지 고르기

탐색기 위쪽의 선택 상자에서 고릅니다.

| 대상 | 설명 |
| --- | --- |
| **로컬 PC** | 내 PC의 파일 |
| **세션 이름 (user@host)** | 연결된 SSH 탭의 서버 파일 (SFTP) |

- 터미널 탭을 클릭하면 탐색기 대상도 **자동으로 그 탭을 따라갑니다**.
- 서버 파일은 그 SSH 탭의 연결을 그대로 쓰므로 **다시 로그인하지 않습니다**.
- SSH 탭을 닫거나 연결이 끊기면 대상이 **로컬 PC**로 돌아갑니다.

## 폴더 이동

| 하고 싶은 것 | 방법 |
| --- | --- |
| 폴더 펼치기 / 접기 | 폴더 클릭 (또는 → / ←) |
| 원하는 경로로 바로 이동 | 경로 칸에 입력하고 Enter |
| 상위 폴더 / 홈 폴더 | 경로 칸 왼쪽의 ↑ / 🏠 |
| 이 폴더부터 보기 | 폴더 우클릭 → **이 폴더를 루트로** |
| 드라이브 목록 (로컬) | `C:\`에서 ↑ |
| 새로 고침 / 모두 접기 | 탐색기 제목 줄의 버튼 |

## 파일 · 폴더 관리

| 하고 싶은 것 | 방법 |
| --- | --- |
| 새 파일 / 새 폴더 | 제목 줄 버튼 또는 우클릭 메뉴 → 이름 입력 후 Enter |
| 이름 바꾸기 | `F2` 또는 우클릭 → **이름 바꾸기** |
| 삭제 | `Delete` 또는 우클릭 → **삭제** (확인 창이 뜸) |
| 복사 / 잘라내기 / 붙여넣기 | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` 또는 우클릭 메뉴 |
| 이동 | 항목을 끌어 다른 폴더에 놓기 (`Ctrl`을 누른 채 놓으면 복사) |
| 여러 개 선택 | `Ctrl`+클릭, `Shift`+클릭, `Ctrl+A` |
| 경로 복사 | 우클릭 → **경로 복사** |

- **삭제**: 로컬 파일은 **휴지통**으로 이동합니다. 서버 파일은 **영구 삭제**되며 되돌릴 수 없습니다. 폴더는 안의 내용까지 모두 삭제됩니다.
- **같은 이름**: 붙여넣거나 옮길 곳에 같은 이름이 있으면 **덮어쓰지 않고** `이름 copy.txt`, `이름 copy 2.txt`처럼 새 이름으로 저장합니다.

## 업로드 · 다운로드 (서버 대상일 때)

| 하고 싶은 것 | 방법 |
| --- | --- |
| 다운로드 | 항목 우클릭 → **다운로드…** → 받을 폴더 선택 (폴더는 통째로) |
| 파일 / 폴더 업로드 | 폴더 우클릭 → **파일 업로드…** / **폴더 업로드…**, 또는 제목 줄의 업로드 버튼 |
| Windows 탐색기에서 끌어다 놓기 | 파일을 탐색기 트리의 **폴더**에 놓으면 그 폴더로, **빈 곳**에 놓으면 현재 폴더로 업로드 |
| 로컬 ↔ 서버 복사 | 로컬 PC 대상에서 `Ctrl+C` → 서버 대상으로 바꿔 `Ctrl+V` (업로드). 반대로 하면 다운로드 |

탐색기 아래쪽 **전송** 목록에서 진행률을 볼 수 있고, X로 취소할 수 있습니다. 다운로드가 끝나면 📂 버튼으로 Windows 탐색기에서 바로 열 수 있습니다.

> 대상이 **로컬 PC**일 때 Windows 탐색기에서 끌어다 놓으면 업로드 대신 그 폴더로 **복사**됩니다.

## 파일 열기

- 파일을 **더블클릭**하면 WLT 안의 **편집기 탭**에서 열립니다 (VS Code와 같은 편집기). 로컬·서버 파일 모두 바로 고치고 `Ctrl+S`로 저장합니다. → [10. 편집기](editor.md)
- 다른 프로그램으로 열려면 우클릭 → **외부 프로그램으로 열기**를 누릅니다. 서버 파일은 아래처럼 동작합니다.

## 서버 파일을 외부 프로그램으로 편집 (저장하면 자동 업로드)

서버의 설정 파일이나 스크립트를 내 PC의 다른 편집기(메모장, VS Code 등)로 고칠 수도 있습니다.

1. 서버 파일을 우클릭 → **외부 프로그램으로 열기 (저장하면 자동 업로드)**를 누릅니다.
2. 파일이 내 PC의 기본 프로그램으로 열립니다.
3. 편집하고 **저장하면**, 잠시 뒤 서버의 원래 위치에 **자동으로 업로드**됩니다.
4. 탐색기 아래 **편집 중** 목록에서 상태를 확인합니다.

   | 표시 | 의미 |
   | --- | --- |
   | 변경 대기 | 열었고, 아직 저장하지 않음 |
   | 업로드 중… | 서버로 올리는 중 |
   | ✔ 업로드됨 14:03:21 | 마지막으로 올린 시각 |
   | ⚠ 업로드 실패 | 이유가 아래에 표시됨. **다시 저장하면 재시도** |

5. 다 고쳤으면 목록의 X로 자동 업로드를 멈춥니다. SSH 연결이 끊겨도 자동으로 멈춥니다.

> ⚠ 저장하면 서버 파일을 **그대로 덮어씁니다**. 그사이 다른 사람이 서버에서 같은 파일을 고쳤는지는 확인하지 않으니, 여러 사람이 함께 쓰는 파일은 주의하세요.

## 터미널과 함께 쓰기

| 메뉴 | 동작 |
| --- | --- |
| **여기서 새 터미널 열기** (로컬) | 그 폴더에서 시작하는 새 로컬 터미널 탭을 엽니다 |
| **터미널에서 이 폴더로 이동 (cd)** (서버) | 그 서버 탭에 `cd '경로'`를 입력합니다 |
| **Windows 탐색기에서 보기** (로컬) | Windows 탐색기에서 그 파일을 선택한 상태로 엽니다 |
| 파일을 터미널에 끌어다 놓기 | 파일 경로가 터미널에 입력됩니다 |

## 키보드

탐색기 트리를 한 번 클릭한 뒤 사용합니다.

| 키 | 동작 |
| --- | --- |
| ↑ / ↓, Home / End | 항목 이동 |
| → / ← | 폴더 펼치기 / 접기 (상위 폴더로) |
| Enter | 폴더 펼치기 / 파일 열기 |
| F2 | 이름 바꾸기 |
| Delete | 삭제 |
| Ctrl+C / X / V | 복사 / 잘라내기 / 붙여넣기 |
| Ctrl+A | 모두 선택 |
| Esc | 선택 해제, 잘라내기 취소 |
