# 10. 편집기

[← 가이드 목차](README.md)

파일 탐색기에서 파일을 **더블클릭**하면 WLT 안의 편집기 탭에서 열립니다. VS Code와 같은 편집기(Monaco)를 사용하므로 단축키와 동작이 VS Code와 같습니다. 로컬 파일과 **서버 파일(SFTP)** 모두 바로 편집하고 저장할 수 있습니다.

## 여는 방법

| 방법 | 결과 |
| --- | --- |
| 탐색기에서 파일 **더블클릭** (또는 선택 후 Enter) | 편집기 탭으로 열기 |
| 파일 우클릭 → **편집기에서 열기** | 위와 같음 |
| 파일 우클릭 → **오른쪽에 분할하여 열기** | 지금 화면 오른쪽에 나란히 열기 |
| 파일 우클릭 → **외부 프로그램으로 열기** | Windows 기본 프로그램으로 열기 (서버 파일은 저장하면 자동 업로드 — [파일 탐색기](file-explorer.md#서버-파일을-외부-프로그램으로-편집-저장하면-자동-업로드)) |

- 이미 열려 있는 파일을 다시 열면 그 탭으로 이동합니다.
- 편집기 탭도 터미널 탭처럼 끌어서 [화면 분할](tabs-and-splits.md#화면-분할-vs-code-방식)할 수 있습니다. 터미널과 편집기를 나란히 두고 작업할 수 있습니다.
- 바이너리 파일(이미지, 실행 파일 등)과 10MB보다 큰 파일은 편집기로 열지 않고, **외부 프로그램으로 열기** 버튼을 보여 줍니다.

## 저장

- `Ctrl+S` 또는 탭 우클릭 → **저장**
- 저장하지 않은 변경 내용이 있으면 탭 이름 옆에 **●**가 표시됩니다.
- 저장하지 않고 탭을 닫거나 WLT를 종료하면 먼저 물어봅니다.
- 파일을 연 뒤 **다른 프로그램(또는 서버의 다른 사용자)이 같은 파일을 바꿨다면**, 저장할 때 덮어쓸지 물어봅니다.
- 서버 파일은 그 SSH 탭의 연결로 저장합니다. SSH 탭을 닫으면 저장할 수 없으니, 서버에 다시 접속한 뒤 탐색기에서 다시 여세요.

## 주요 단축키 (VS Code와 같음)

| 키 | 동작 |
| --- | --- |
| `Ctrl+S` | 저장 |
| `Ctrl+F` / `Ctrl+H` | 찾기 / 바꾸기 |
| `Ctrl+G` | 줄로 이동 |
| `Ctrl+D` | 같은 단어 다음 항목 추가 선택 (멀티 커서) |
| `Alt+클릭`, `Ctrl+Alt+↑/↓` | 커서 추가 |
| `Ctrl+/` | 주석 토글 |
| `Alt+↑/↓` | 줄 이동 |
| `Shift+Alt+↑/↓` | 줄 복사 |
| `Ctrl+Shift+K` | 줄 삭제 |
| `Ctrl+[` / `Ctrl+]` | 들여쓰기 줄이기 / 늘리기 |
| `Ctrl+Shift+[` / `Ctrl+Shift+]` | 코드 접기 / 펴기 |
| `Alt+Z` | 줄 바꿈(Word Wrap) 켜기·끄기 |
| `F1` | 명령 팔레트 (모든 편집기 명령) |
| `Ctrl` + 마우스 스크롤 | 편집기 글꼴 확대·축소 |
| 우클릭 | 편집기 메뉴 (잘라내기·복사·붙여넣기, 명령 팔레트 등) |

## 상태 표시줄 (편집기 아래)

```text
로컬 · C:\proj\src\main.rs          줄 12, 열 8   UTF-8   LF   Rust
```

| 항목 | 설명 |
| --- | --- |
| 로컬 / SFTP · 경로 | 파일 위치 |
| 줄, 열 | 커서 위치 |
| **인코딩** | 클릭하면 UTF-8 → UTF-8 with BOM → EUC-KR 순서로 바뀝니다. 저장할 때 그 인코딩으로 저장합니다 |
| **줄 끝 문자** (LF / CRLF) | 클릭하면 바뀝니다 |
| 언어 | 파일 확장자·이름으로 자동 선택 |

### 인코딩

- UTF-8 파일은 그대로, **UTF-8이 아닌 파일은 EUC-KR(CP949)** 로 읽습니다. 예전 Windows에서 만든 한글 텍스트 파일이 깨지지 않습니다.
- 저장할 때는 **열 때의 인코딩과 줄 끝 문자를 그대로** 유지합니다. 바꾸고 싶을 때만 상태 표시줄에서 클릭하세요.

## 지원 범위

- **문법 강조**: 80여 개 언어 (Python, JavaScript/TypeScript, Rust, Go, Java, C/C++, C#, Shell, PowerShell, SQL, YAML, JSON, XML, HTML, CSS, Markdown, Dockerfile, INI 등)
- 찾기·바꾸기(정규식), 멀티 커서, 코드 접기, 괄호 짝 표시, 미니맵, 명령 팔레트
- 테마와 글꼴은 WLT 설정(테마, 글꼴, 크기, 합자)을 그대로 따릅니다.
- **자동 완성·오류 검사(IntelliSense)는 없습니다.** 앱 크기를 줄이기 위해 언어 분석 기능은 넣지 않았습니다. 본격적인 개발 작업에는 VS Code를 함께 쓰세요.
- 편집기 탭은 세션 히스토리에 기록되지 않습니다.
