# 8. 문제 해결

[← 가이드 목차](README.md)

## 실행 · 설치

**`wlt.exe`를 실행해도 아무 반응이 없어요.**

- 포터블로 실행했다면 같은 폴더에 `WebView2Loader.dll`이 있는지 확인하세요.
- WebView2 런타임이 없는 PC라면 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)을 설치하세요.

**작업 표시줄에 고정했는데 실행하면 아이콘이 하나 더 생겨요.**

- 설치 파일로 설치한 WLT를 시작 메뉴에서 고정하세요. 예전 버전으로 고정했다면 고정을 해제하고 다시 고정하세요.

## SSH 접속

**`connection to … timed out`**

- 주소와 포트가 맞는지, 방화벽이나 VPN 때문에 막히지 않았는지 확인하세요.

**`authentication failed (password)`**

- 비밀번호를 확인하세요. 저장된 비밀번호가 바뀌었다면 세션 편집에서 새 비밀번호를 입력하고 저장하세요. 또는 [자격 증명 관리자](ssh-sessions.md#저장된-항목-확인--삭제)에서 항목을 지우면 다음 접속 때 다시 묻습니다.

**`authentication failed (public key)` / `private key not found`**

- 개인 키 경로가 맞는지 확인하세요. 서버의 `~/.ssh/authorized_keys`에 공개 키가 등록되어 있어야 합니다.

**`authentication failed (agent) — …`**

- 표시된 이유를 참고하세요. → [에이전트 인증이 실패하면](ssh-sessions.md#에이전트-인증이-실패하면)

**`REMOTE HOST IDENTIFICATION HAS CHANGED!`**

- 서버 키가 바뀌었습니다. 서버를 새로 설치한 것이 확실할 때만 경고에 나온 줄을 `%APPDATA%\com.wlt.terminal\known_hosts`에서 지우고 다시 접속하세요. → [서버 키 확인](ssh-sessions.md#서버-키-확인-보안)

**한글이 깨져 보여요.**

- 서버의 로케일이 UTF-8인지 확인하세요 (`locale` 명령에서 `UTF-8`이 보여야 함).

## 파일 탐색기

**탐색기 대상 목록에 서버가 없어요.**

- 서버 탭이 **연결된 상태**(🟢)일 때만 목록에 나옵니다.

**`server refused SFTP`**

- 서버에서 SFTP가 꺼져 있습니다. 서버의 `/etc/ssh/sshd_config`에 `Subsystem sftp …` 줄이 있는지 서버 관리자에게 확인하세요.

**서버 파일을 고치고 저장했는데 올라가지 않아요.**

- 탐색기 아래 **편집 중** 목록에서 상태를 확인하세요. **업로드 실패**라면 표시된 이유(권한 등)를 확인하고 다시 저장하세요.
- 목록에 파일이 없다면 자동 업로드가 멈춘 상태입니다(연결이 끊겼거나 X로 중지). 탐색기에서 파일을 다시 여세요.

**Windows 탐색기에서 끌어다 놓았는데 아무 일도 없어요.**

- WLT의 **탐색기 트리 위**(폴더나 빈 곳)에 놓아야 합니다. 사이드바가 터미널 메뉴일 때는 탐색기 메뉴로 바꾼 뒤 놓으세요.

**같은 이름 파일이 `copy`가 붙어서 생겨요.**

- 덮어쓰기를 막기 위한 동작입니다. 바꾸려면 기존 파일을 먼저 지우거나 이름을 바꾸세요.

## 세션 히스토리

**히스토리에서 복귀했는데 홈 폴더에서 시작해요.**

- 그 셸이 현재 폴더를 알려 주지 않은 경우입니다. 설정 → 세션 히스토리의 **셸 통합**이 켜져 있는지 확인하세요. SSH 서버는 bash·zsh에서만 자동 지원되며, 그 밖의 셸은 창 제목으로 추측합니다. → [작업 폴더는 어떻게 아나요?](session-history.md#작업-폴더는-어떻게-아나요-셸-통합)

**SSH 접속할 때 이상한 명령이 한 줄 보여요.**

- 셸 통합 명령입니다. 보통은 바로 지워지지만, 화면 폭이 좁거나 프롬프트가 길면 남을 수 있습니다. 설정에서 **SSH 접속 시 셸 통합 명령 자동 입력**을 끌 수 있습니다.

**탭을 닫았는데 히스토리에 없어요.**

- 정상입니다. 기본 설정에서는 **앱을 종료할 때 열려 있던 탭만** 기록하고, 직접 닫은 탭은 남기지 않습니다. 닫은 탭도 남기려면 설정 → 세션 히스토리 → **탭을 직접 닫을 때도 히스토리에 저장**을 켜세요.

**닫은 탭이 🟢가 아니라 ⚪로 나와요.** ("직접 닫은 탭도 저장"을 켠 경우)

- 보관 시간(기본 30분)이 지났거나, 보관 개수(기본 5개)를 넘었거나, 이미 연결이 끊긴 탭이었습니다. 설정에서 시간과 개수를 늘릴 수 있습니다.

## 화면

**화면이 깨지거나 글자가 이상하게 그려져요.**

- 설정에서 **WebGL 렌더러**를 끄고 다시 확인하세요.

**밝은 테마에서 일부 글자가 흐려요.**

- 자동으로 대비를 높이지만, 서버 프로그램이 흰색 글자를 쓰는 경우 잘 안 보일 수 있습니다. 어두운 테마를 쓰거나 서버 쪽 색상 설정을 바꿔 보세요.

## 로그

**로그 파일이 안 생겨요.**

- 설정의 **로그 저장**을 켠 뒤 **새로 열거나 다시 연결한 탭**부터 기록됩니다. 터미널 첫 줄에 `● 로그 기록 중: 경로`가 보이는지 확인하세요.
