# 11. 파일 내용 검색

[← 가이드 목차](README.md)

작업 표시줄의 🔍 아이콘(세션 히스토리 아래)을 누르거나 `Ctrl+Shift+G`를 누르면 검색 창이 열립니다. VS Code의 "파일에서 찾기"처럼 **폴더 안 모든 파일의 내용**에서 글자를 찾고, 결과를 클릭하면 [편집기](editor.md)에서 그 줄이 열립니다. **로컬 PC와 서버(SSH) 폴더 모두** 검색할 수 있습니다.

## 사용법

1. 검색 칸에 찾을 글자를 입력합니다. 입력을 멈추면 바로 검색합니다(Enter를 눌러도 됨).
2. 결과는 파일별로 묶여 나타납니다. 파일 이름 옆 숫자는 그 파일의 결과 수입니다.
3. 결과 줄을 클릭하면 편집기 탭이 열리고, 그 줄로 이동해 찾은 글자가 선택됩니다.

```text
검색  [ hello              Aa ab .* ]
      [ 포함할 파일 (예: *.py, src/**) ]
      [ 제외할 파일 (예: *.log, test)   ]
      검색 위치: 로컬 PC · C:\proj            📂
      2개 파일에서 3개 결과
      ▾ main.rs   src                          2
          println!("Hello 한글");               2
          hello();                              3
      ▾ notes.txt                              1
          say HELLO twice                       1
```

## 검색 옵션

| 버튼 / 칸 | 설명 |
| --- | --- |
| **Aa** | 대소문자 구분 |
| **ab** | 단어 단위로 찾기 (`log`를 찾을 때 `login`은 제외) |
| **.\*** | 정규식 사용 (예: `err(or)?\s+\d+`) |
| **포함할 파일** | 쉼표로 구분한 패턴. `*.py` (모든 하위 폴더의 .py), `src/**` (src 폴더 아래) |
| **제외할 파일** | 쉼표로 구분한 패턴. `*.log`, `test` (test라는 파일·폴더) |

다음 폴더는 항상 검색에서 빠집니다: `.git`, `node_modules`, `target`, `dist`, `build`, `.venv`, `venv`, `__pycache__`, `.idea`, `.vscode`, `.cache`, `.next`, `.gradle`. 바이너리 파일과 2MB보다 큰 파일(로컬)도 건너뜁니다.

## 검색 위치

- 처음에는 **파일 탐색기에서 보고 있던 폴더**(로컬 PC 또는 서버)에서 검색합니다.
- 📂 버튼을 누르면 탐색기의 현재 폴더로 다시 맞춥니다.
- 탐색기에서 폴더(또는 빈 곳)를 우클릭 → **이 폴더에서 검색**을 누르면 그 폴더에서 바로 검색합니다.

### 로컬 PC와 서버의 차이

| | 로컬 PC | 서버 (SSH) |
| --- | --- | --- |
| 검색하는 곳 | WLT가 파일을 직접 읽어서 검색 | **서버가 `grep`으로 검색**하고 결과만 받아옴 (파일을 내려받지 않아 빠름) |
| 한글 파일 | UTF-8과 EUC-KR(CP949) 모두 | 서버의 grep이 처리 (보통 UTF-8) |
| 정규식 | Rust 정규식 | grep 확장 정규식(`-E`). 문법이 조금 다를 수 있음 |

- 서버 검색에는 서버에 `grep`이 있어야 합니다(대부분의 Linux에 기본 포함).
- 서버 검색은 그 SSH 탭의 연결을 사용하므로, 탭이 연결되어 있어야 합니다.

## 그 밖에

- 결과는 최대 2,000개까지 표시합니다. 더 많으면 "결과가 많아 일부만 표시합니다"가 나오니 검색어를 좁히거나 포함할 파일을 지정하세요.
- 검색 중에는 **중지**로 멈출 수 있습니다. 검색어를 바꾸면 이전 검색은 자동으로 멈춥니다.
- 제목 줄의 버튼: 다시 검색 · 모두 접기 · 지우기
- 다른 사이드바 메뉴를 보다 돌아와도 검색 결과는 남아 있습니다.
- 터미널 화면 안에서 찾기는 `Ctrl+Shift+F`입니다 (이 검색과는 별개).
