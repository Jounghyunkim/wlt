# 6. 설정과 세션 로그

[← 가이드 목차](README.md)

작업 표시줄 맨 아래의 ⚙ **설정**을 누르면 설정 창이 열립니다. 바꾼 내용은 바로 모든 탭에 적용되고 자동으로 저장됩니다. **기본값으로**를 누르면 처음 상태로 돌아갑니다.

## 화면

| 설정 | 설명 |
| --- | --- |
| **테마** | 10종 (아래 표). 탭마다 다른 테마를 쓰려면 탭 우클릭 → [탭 테마](tabs-and-splits.md#탭-테마). 밝은 테마에서는 흐린 색 글자가 잘 보이도록 자동으로 진하게 표시합니다. |
| **글꼴** | 아래 표 참고 |
| **크기 / 줄 간격** | 글꼴 크기(8–32)와 줄 간격 |
| **커서 모양 / 깜박임** | 블록 █, 막대 ▏, 밑줄 _ |
| **스크롤백** | 위로 스크롤해서 볼 수 있는 줄 수 (기본 10,000줄) |
| **작업 표시줄 · 사이드바 위치** | 왼쪽 / 오른쪽 |
| **탐색기 시작 폴더** | 탐색기가 처음 열 로컬 폴더 (비우면 홈 폴더). 서버별 시작 폴더 초기화 → [루트(시작) 폴더 지정](file-explorer.md#루트시작-폴더-지정) |
| **기본 로컬 셸** | `Ctrl+Shift+T`, `+`로 열 셸 |
| **선택 시 자동 복사** | 마우스로 선택하면 바로 복사 (PuTTY 방식) |
| **WebGL 렌더러** | GPU 가속. 화면이 깨지거나 느리면 꺼 보세요. |
| **합자 (Ligatures)** | `=>`, `!=`, `->` 등을 하나의 기호처럼 표시. 새 탭부터 적용 |

### 테마

| 종류 | 테마 |
| --- | --- |
| 기본 (단색) | Dracula, Nord, One Dark, VS Code Dark, Light (밝음), Solarized Light (밝음) |
| **배경 무늬·그림** | **Synthwave** (네온 격자 + 보라색 지평선), **Starry Night** (별이 뜬 밤하늘과 산 능선), **Blueprint** (설계도 격자), **Hanji** (한지 질감, 밝음) |

- 배경 무늬·그림 테마는 글자 뒤에 무늬가 깔리고, 글자가 잘 읽히도록 무늬는 은은하게 그려집니다. 그림 파일 없이 코드로 그려서 창 크기에 상관없이 선명합니다.
- 편집기 탭은 무늬 없이 그 테마의 바탕색을 씁니다.
- 설정 창과 탭 테마 메뉴의 미리보기에도 무늬가 함께 보입니다.

### 글꼴

| 종류 | 글꼴 |
| --- | --- |
| 앱에 포함 (설치 불필요) | JetBrains Mono, Cascadia Code, Fira Code, Source Code Pro, IBM Plex Mono, Roboto Mono, Ubuntu Mono, Inconsolata, Victor Mono |
| Windows 시스템 글꼴 | Consolas, Cascadia Mono, Courier New, Lucida Console, D2Coding (설치된 경우) |

한글은 위 글꼴에 없으면 맑은 고딕 등 시스템 글꼴로 표시됩니다. 한글까지 고정폭으로 맞추고 싶다면 D2Coding을 설치하고 선택하세요.

### 사이드바 너비

사이드바 안쪽 경계를 끌면 너비가 바뀌고(180–600px), 더블클릭하면 기본 너비로 돌아갑니다. 너비는 저장됩니다.

## 세션 히스토리

설정 창의 **세션 히스토리**에서 닫은 탭 보관 시간·개수, 화면 기록 저장, 셸 통합을 설정합니다. → [9. 세션 히스토리](session-history.md#설정)

## 세션 로그 (입출력 기록 저장)

설정 창 아래쪽 **세션 로그**에서 켜면, 각 패널(탭)의 입력과 출력을 파일로 저장합니다. 작업 기록을 남기거나 나중에 출력 결과를 찾아볼 때 유용합니다.

> 설정을 바꾸면 **그다음에 새로 열거나 다시 연결한 탭부터** 적용됩니다.

| 설정 | 기본값 | 설명 |
| --- | --- | --- |
| **로그 저장** | 끔 | 전체 켜기 / 끄기 |
| **출력 저장** | 켬 | 화면에 나온 내용을 `.log` 파일에 저장 |
| **입력 저장** | 끔 | 입력한 명령을 Enter 단위로 `.input.log`에 저장. 줄마다 날짜·시간 기록 |
| **제어 문자 제거** | 켬 | 색상·커서 이동 코드를 빼고 읽기 쉬운 텍스트로 저장. 끄면 받은 내용을 그대로 저장 |
| **출력 줄마다 시간 기록** | 끔 | 출력 줄 앞에 `[HH:MM:SS]`를 붙임 (제어 문자 제거가 켜져 있을 때만) |
| **저장 폴더** | `문서\WLT Logs` | 비워 두면 기본 폴더. 그 아래 날짜별 폴더에 저장 |

**로그 폴더 열기** 버튼을 누르면 Windows 탐색기에서 로그 폴더가 열립니다.

### 파일 이름과 내용

```text
문서\WLT Logs\
└─ 2026-11-03\
   ├─ 143005_prod-web-01.log          ← 출력
   └─ 143005_prod-web-01.input.log    ← 입력
```

- 로그가 시작되면 터미널 첫 줄에 저장 경로가 회색으로 표시됩니다(이 줄은 로그에 들어가지 않음).
- 파일의 처음과 끝에 탭 이름, 접속 대상, 시작·종료 시각이 기록됩니다.

출력 로그 예:

```text
===== WLT output log: prod-web-01 (ssh user@10.0.0.5:22) — started 2026-11-03 14:30:05 =====
[14:30:07] user@web01:~$ df -h
[14:30:07] Filesystem      Size  Used Avail Use% Mounted on
...
```

입력 로그 예:

```text
===== WLT input log: prod-web-01 (ssh user@10.0.0.5:22) — started 2026-11-03 14:30:05 =====
[2026-11-03 14:30:07] df -h
[2026-11-03 14:30:15] sudo systemctl restart nginx
```

### 주의

- ⚠ **입력 로그에는 `sudo` 등 셸 안에서 입력한 비밀번호도 그대로 기록될 수 있습니다.** 입력 저장을 켜면 설정 창에 경고가 표시됩니다. SSH 접속 비밀번호는 기록되지 않습니다.
- `vim`, `top`처럼 화면 전체를 다시 그리는 프로그램은, 제어 문자를 제거한 로그에서 순서가 섞여 보일 수 있습니다. 정확한 기록이 필요하면 **제어 문자 제거**를 끄세요.

## 저장 위치 정리

| 무엇 | 위치 |
| --- | --- |
| 세션 목록 · 설정 | WLT 앱 데이터 (`%LOCALAPPDATA%\com.wlt.terminal`) |
| 저장한 비밀번호 · 키 암호 | Windows 자격 증명 관리자 (`WLT/ssh/…`) |
| 서버 키 (known_hosts) | `%APPDATA%\com.wlt.terminal\known_hosts` |
| 세션 로그 | `문서\WLT Logs` (설정에서 변경 가능) |
| 편집 중인 서버 파일의 임시 사본 | `%TEMP%\WLT\edit\` |
| 세션 히스토리 화면 기록 | `%LOCALAPPDATA%\com.wlt.terminal\history\` |

다른 PC로 설치하면 세션 목록과 설정은 옮겨지지 않습니다.
