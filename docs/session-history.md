# 9. 세션 히스토리

[← 가이드 목차](README.md)

**WLT를 종료할 때 열려 있던 탭들이 세션 히스토리에 남습니다.** 다음에 WLT를 켜서 히스토리 항목을 클릭하면, 같은 셸·서버로 다시 연결해 **작업하던 폴더로 돌아가고, 파일 탐색기도 그 폴더로 맞춰집니다.** 이전 화면 기록도 함께 보여 줍니다.

작업 표시줄의 🕘 아이콘을 누르거나 `Ctrl+Shift+H`를 누르면 열립니다.

> 탭의 X(또는 가운데 클릭, `Ctrl+Shift+W`, 탭 메뉴의 **탭 닫기**)로 **직접 닫은 탭은 히스토리에 남지 않습니다.** 닫은 탭도 남기고 싶다면 [설정](#설정)에서 **탭을 직접 닫을 때도 히스토리에 저장**을 켜세요.

## 사용법

1. 평소처럼 작업하다가 WLT를 종료합니다(창의 X, `Alt+F4` 등). 이때 열려 있던 탭이 모두 히스토리에 기록됩니다. 잠긴 탭도 포함됩니다.
2. 다음에 WLT를 켜고 🕘 세션 히스토리를 엽니다.
3. 돌아갈 항목을 **클릭**합니다.

클릭하면 이렇게 동작합니다.

1. 같은 셸(로컬) 또는 같은 서버(SSH)에 새로 연결합니다.
2. **마지막 폴더로 이동**합니다. 로컬은 그 폴더에서 셸을 시작하고, SSH는 접속 후 자동으로 `cd`합니다.
3. 이전 화면 기록이 회색 구분선 위에 먼저 표시됩니다.

   ```text
   ...이전 화면 내용...
   ── 이전 세션 기록 (2026. 11. 3. 오후 6:02) ── 여기부터 새 세션 ──
   ```

4. 파일 탐색기도 그 폴더로 맞춰집니다.
5. 탭 이름과 탭별 글꼴 크기가 돌아옵니다.

> 💡 새로 연결하는 것이라, 실행 중이던 프로그램이나 셸 변수는 돌아오지 않습니다. 서버 작업을 완전히 이어가야 한다면 서버에서 `tmux`를 쓰는 것이 가장 확실합니다.

각 항목에는 탭 이름, 기록된 시각, 대상(셸 이름 또는 `user@host`), 마지막 폴더가 표시되고, 오늘 / 어제 / 이전으로 나뉩니다.

### 우클릭 메뉴

| 메뉴 | 설명 |
| --- | --- |
| **다시 연결해서 복귀** | 클릭과 같음 |
| **오른쪽에 분할하여 복귀** | 지금 화면 오른쪽에 나란히 엽니다 |
| **경로 복사** | 마지막 폴더 경로를 클립보드로 |
| **탐색기에서 열기** (로컬) | 연결하지 않고 그 폴더를 파일 탐색기로 엽니다 |
| **히스토리에서 삭제** | 항목과 저장된 화면 기록을 지웁니다 |

- 검색 칸에서 이름·호스트·폴더로 찾을 수 있습니다.
- 같은 셸·서버의 같은 폴더는 항목 하나로 합쳐집니다.
- 복귀한 항목은 목록에서 빠지고, 그 탭이 열린 채로 다시 종료하면 새로 기록됩니다.
- 제목 줄의 🗑로 모두 지울 수 있습니다.

## 선택 기능: 직접 닫은 탭도 저장하기

설정 → 세션 히스토리 → **탭을 직접 닫을 때도 히스토리에 저장**을 켜면, 직접 닫은 탭도 히스토리에 남고 닫은 뒤 잠시 **살려 둡니다**.

| 표시 | 언제 | 무엇이 돌아오나 |
| --- | --- | --- |
| 🟢 **이어서 작업 가능 (보관 중)** | 닫은 뒤 **30분 안** (최대 5개) | **전부 그대로**: 실행 중이던 프로그램(`top`, 빌드, `vim` 등), 화면 내용, 셸 상태. 탭을 화면에서만 뺐을 뿐 셸과 연결은 살아 있습니다. |
| ⚪ **다시 연결해서 복귀** | 보관 시간이 지났거나, 앱을 다시 켠 뒤 | 위 "사용법"과 같음 |

- 작업 표시줄의 🕘 아이콘에 붙은 초록 숫자는 **지금 보관 중인 세션 수**입니다.
- 보관 중인 항목의 우클릭 메뉴에는 **새 연결로 열기**(보관 중인 세션을 끝내고 새로 연결)와 **보관 종료**(⏻, 지금 끝내고 ⚪로 남김)가 추가됩니다.
- 이 기능이 켜져 있을 때는 탭 메뉴에 **닫기 (보관하지 않고 바로 종료)**가 나타납니다.
- 보관 중인 세션은 화면에 보이지 않을 뿐 셸 프로세스와 SSH 연결이 계속 살아 있어 메모리와 연결을 사용합니다. 그래서 시간과 개수를 제한합니다.

## 작업 폴더는 어떻게 아나요? (셸 통합)

셸이 프롬프트를 그릴 때마다 현재 폴더를 WLT에 알려 주도록 설정합니다. VS Code, Windows Terminal과 같은 방식이며, **사용자 프로필 파일(.bashrc, $PROFILE 등)은 바꾸지 않습니다.**

| 셸 | 동작 |
| --- | --- |
| PowerShell, cmd, Git Bash, WSL | WLT가 셸을 실행할 때 자동 적용 |
| SSH 서버 (bash · zsh) | 접속 직후 셸 통합 명령 한 줄을 자동으로 입력하고, 입력한 줄은 화면에서 지웁니다 |
| 그 밖의 셸 | 서버가 보내는 창 제목(`user@host: ~/dir`, Ubuntu 기본값)에서 폴더를 읽습니다 |

- 폴더를 알 수 없는 탭은 히스토리에 "폴더 정보 없음"으로 남고, 복귀하면 홈 폴더에서 시작합니다.
- 복귀하려는 폴더가 지워졌다면 경고가 한 줄 표시됩니다. 로컬은 홈 폴더에서 시작하고, SSH는 원래 위치에 머뭅니다.

> SSH 셸 통합 명령은 서버의 셸 히스토리에 남지 않도록 앞에 공백을 붙여 보냅니다(Ubuntu 등 `HISTCONTROL=ignoreboth` 기본 설정 기준). 서버 환경에 따라 한 줄이 잠깐 보일 수 있으며, 설정에서 끌 수 있습니다.

### 덤: 탐색기가 터미널 폴더 따라가기

설정 → 세션 히스토리 → **탐색기가 터미널의 현재 폴더 따라가기**를 켜면, 터미널에서 `cd`할 때마다 파일 탐색기가 그 폴더로 따라갑니다.

## 설정

설정 → **세션 히스토리**

| 설정 | 기본값 | 설명 |
| --- | --- | --- |
| 탭을 직접 닫을 때도 히스토리에 저장 | **끔** | 끄면 앱을 종료할 때 열려 있던 탭만 기록. 켜면 [선택 기능](#선택-기능-직접-닫은-탭도-저장하기) 참고 |
| └ 닫은 탭 보관 시간 (분) | 30 | 위 옵션이 켜져 있을 때만. 🟢로 이어서 작업할 수 있는 시간 (0이면 보관 안 함) |
| └ 최대 보관 개수 | 5 | 위 옵션이 켜져 있을 때만 |
| 화면 기록 저장 (줄) | 1,000 | 복귀할 때 보여 줄 이전 화면 줄 수. **0이면 저장 안 함** |
| 히스토리 최대 개수 | 100 | 넘으면 오래된 항목부터 지워짐 |
| 셸 통합 (로컬) | 켬 | 로컬 셸의 현재 폴더 추적 |
| SSH 셸 통합 명령 자동 입력 | 켬 | 끄면 서버가 스스로 보내는 정보(창 제목 등)만 사용 |
| 탐색기가 터미널 폴더 따라가기 | 끔 | 위 "덤" 참고 |

## 저장되는 것 · 저장되지 않는 것

| 항목 | 저장 위치 |
| --- | --- |
| 히스토리 목록 (탭 이름, 대상, 마지막 폴더, 기록 시각, 탭별 글꼴 크기) | WLT 앱 데이터 |
| 이전 화면 기록 | `%LOCALAPPDATA%\com.wlt.terminal\history\` (항목을 지우면 함께 삭제) |
| 접속할 때 직접 입력한 비밀번호 | **저장 안 함** — 저장한 비밀번호는 자격 증명 관리자에서 읽고, 아니면 복귀 때 다시 물음 |

> ⚠ 화면 기록에는 화면에 나왔던 내용(토큰, 출력된 비밀번호 등)이 그대로 들어 있을 수 있습니다. 공용 PC에서는 **화면 기록 저장을 0**으로 두세요.
