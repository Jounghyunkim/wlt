# 1. 시작하기

[← 가이드 목차](README.md)

## 설치

### 설치 파일로 설치 (권장)

1. `WLT_0.1.0_x64-setup.exe`를 실행합니다.
2. 안내에 따라 설치합니다. 관리자 권한은 필요 없으며, 내 사용자 폴더(`%LOCALAPPDATA%\WLT`)에 설치됩니다.
3. 마지막 화면에서 **바탕 화면 바로 가기 만들기**와 **WLT 실행**을 선택할 수 있습니다.

설치하면 시작 메뉴에 **WLT**가 등록됩니다. 작업 표시줄에 고정하려면 시작 메뉴의 WLT를 오른쪽 클릭하거나, 실행 중인 WLT 아이콘을 오른쪽 클릭한 뒤 **작업 표시줄에 고정**을 누르세요.

### 설치 없이 실행 (포터블)

아래 두 파일을 **같은 폴더**에 두고 `wlt.exe`를 실행합니다.

```text
wlt.exe
WebView2Loader.dll
```

### 필요한 환경

- Windows 10 또는 11 (64비트)
- Microsoft WebView2 런타임: Windows 11과 최신 Windows 10에는 기본으로 들어 있습니다. 없으면 설치 파일이 자동으로 받아 설치합니다. 포터블로 실행할 때는 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)을 직접 설치하세요.

## 화면 구성

```text
┌──┬──────────────┬──────────────────────────────────────┐
│🖥│ 사이드바      │ [탭1] [탭2] [+]                  [⫴] │ ← 탭 줄
│📄│              │                                      │
│🕘│ 터미널 목록   │            터미널 화면                │
│  │  또는         │                                      │
│  │ 파일 탐색기   │                                      │
│⚙│              │                                      │
└──┴──────────────┴──────────────────────────────────────┘
 ↑ 작업 표시줄
```

| 영역 | 설명 |
| --- | --- |
| **작업 표시줄** (맨 왼쪽 아이콘 줄) | 🖥 터미널, 📄 탐색기, 🕘 세션 히스토리, ⚙ 설정. 이미 선택된 아이콘을 다시 누르면 사이드바가 접힙니다. |
| **사이드바** | 터미널 메뉴에서는 로컬 셸과 SSH 세션 목록을, 탐색기 메뉴에서는 파일 탐색기를, 세션 히스토리 메뉴에서는 닫은 탭 목록을 보여 줍니다. 오른쪽 경계를 끌어 너비를 조절할 수 있습니다. |
| **탭 줄** | 열린 터미널 탭. `+`는 새 로컬 터미널, 오른쪽 끝 버튼은 오른쪽에 새 터미널 분할입니다. |
| **터미널 화면** | 탭을 끌어 화면을 나눌 수 있습니다. → [탭과 화면 분할](tabs-and-splits.md) |

작업 표시줄과 사이드바는 설정에서 **오른쪽**으로 옮길 수 있습니다.

## 첫 로컬 터미널 열기

- 사이드바의 **로컬 셸** 목록에서 원하는 셸(PowerShell, Command Prompt, WSL, Git Bash 등)을 클릭합니다.
- 또는 `Ctrl+Shift+T`를 누르거나 탭 줄의 `+`를 누르면 기본 셸이 열립니다.

설치되어 있는 셸만 목록에 나옵니다. 기본 셸은 [설정](settings-and-logs.md)에서 바꿀 수 있습니다.

## 첫 SSH 서버 접속

1. 사이드바 **터미널** 메뉴의 `+`(새 SSH 세션)를 누릅니다.
2. 접속 정보를 입력합니다.
   - **호스트**: 서버 주소. `user@host:port` 형식으로 붙여 넣으면 사용자 이름과 포트가 자동으로 채워집니다.
   - **포트**: 기본 22
   - **사용자 이름**
   - **인증 방식**: 비밀번호 / 개인 키 / SSH 에이전트 → [SSH 세션과 인증](ssh-sessions.md)
3. **저장 후 연결**을 누릅니다.
4. 처음 접속하는 서버라면 터미널에 아래와 같은 노란 안내가 표시되고, 서버 키가 저장됩니다.

   ```text
   Warning: permanently added '서버주소' (ssh-ed25519) to known hosts.
   ```

다음부터는 사이드바의 세션을 **더블클릭**하면 바로 접속합니다.

## 연결이 끊겼을 때

탭의 상태 점이 회색(종료) 또는 빨간색(오류)이 되면, 그 탭에서 **Enter**를 누르세요. 같은 설정으로 다시 연결합니다.

| 상태 점 | 의미 |
| --- | --- |
| 🟡 깜빡임 | 연결 중 |
| 🟢 | 연결됨 |
| ⚪ | 종료됨 (Enter로 다시 연결) |
| 🔴 | 오류 (Enter로 다시 연결) |
