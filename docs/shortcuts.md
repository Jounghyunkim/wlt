# 7. 단축키

[← 가이드 목차](README.md)

## 키보드

### 탭 · 화면

| 키 | 동작 |
| --- | --- |
| `Ctrl+Shift+T` | 새 로컬 탭 |
| `Ctrl+Shift+W` | 현재 탭 닫기 (잠긴 탭 제외) |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 현재 창 안에서 다음 / 이전 탭 |
| `Ctrl+Shift+\` | 오른쪽에 새 터미널 분할 |
| `Ctrl+Shift+B` | 사이드바 열기 / 닫기 |
| `Ctrl+Shift+E` | 파일 탐색기 |
| `Ctrl+Shift+H` | 세션 히스토리 (지난번 작업하던 탭으로 돌아가기) |
| `Ctrl+Shift+G` | 파일 내용 검색 |

### 터미널

| 키 | 동작 |
| --- | --- |
| `Ctrl+Shift+C` / `Ctrl+Shift+V` | 복사 / 붙여넣기 |
| `Ctrl+Shift+A` | 전체 선택 ("선택 시 자동 복사"가 켜져 있으면 바로 복사됨) |
| `Ctrl+Shift+F` | 터미널 내 검색 |
| `Ctrl` + `=` / `-` | 모든 탭의 글꼴 확대 / 축소 |
| `Ctrl` + `0` | 글꼴 크기 초기화 (현재 탭의 개별 크기도 해제) |
| 연결이 끊긴 탭에서 `Enter` | 다시 연결 |

### 편집기

| 키 | 동작 |
| --- | --- |
| `Ctrl+S` | 저장 |
| `Ctrl+F` / `Ctrl+H` | 찾기 / 바꾸기 |
| `Alt+Z` | 줄 바꿈 켜기·끄기 |
| `F1` | 명령 팔레트 |

그 밖의 편집 단축키는 VS Code와 같습니다. → [10. 편집기](editor.md#주요-단축키-vs-code와-같음)

### 파일 탐색기 (트리를 클릭한 뒤)

| 키 | 동작 |
| --- | --- |
| `↑` `↓` `Home` `End` | 항목 이동 |
| `→` / `←` | 폴더 펼치기 / 접기 |
| `Enter` | 폴더 펼치기 / 파일을 편집기로 열기 |
| `F2` | 이름 바꾸기 |
| `Delete` | 삭제 |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | 복사 / 잘라내기 / 붙여넣기 |
| `Ctrl+A` | 모두 선택 |
| `Esc` | 선택 해제 |

## 마우스

| 동작 | 결과 |
| --- | --- |
| 터미널 우클릭 | 선택 영역이 있으면 복사, 없으면 붙여넣기 (PuTTY 방식) |
| 터미널에서 `Ctrl` + 스크롤 | 현재 탭만 글꼴 확대 / 축소 |
| 탭 우클릭 | 탭 메뉴 (이름 변경, 잠금, 탭 테마, 텍스트 복사, 복제, 다시 연결, 닫기) |
| 탭 더블클릭 | 탭 이름 변경 |
| 탭 가운데 클릭 | 탭 닫기 |
| 탭 끌기 → 창 가장자리 / 가운데 / 탭 줄 | 화면 분할 / 그 창으로 이동 / 순서 변경 |
| 창 경계선 · 사이드바 경계 끌기 | 크기 조절 (더블클릭하면 기본값) |
| 사이드바의 SSH 세션 · 로컬 셸 끌기 | 목록 순서 변경 (탭 줄 `+` 메뉴에도 적용) |
| 작업 표시줄의 선택된 아이콘 다시 클릭 | 사이드바 접기 |
| 세션 더블클릭 | SSH 접속 |
| 세션 히스토리 항목 클릭 | 그 탭으로 복귀 (작업 폴더 + 탐색기 동기화) |
| 탐색기 항목 끌기 (`Ctrl` 누르면 복사) | 다른 폴더로 이동 |
| Windows 탐색기 파일 → 탐색기 트리 | 업로드 (로컬 대상이면 복사) |
| Windows 탐색기 파일 → 터미널 | 파일 경로 입력 |
