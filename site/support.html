주요 기능

  • 터미널: PowerShell · cmd · WSL · Git Bash 자동 감지, SSH (비밀번호 · 개인 키 · SSH 에이전트)
  • 탭과 화면 분할: 탭을 끌어 상하좌우로 분할, 연결을 유지한 채 이동
  • 파일 탐색기: 로컬 PC와 서버(SFTP) 파일 관리, 업로드 · 다운로드, 끌어다 놓기
  • 편집기 · 검색: 로컬 · 서버 파일을 바로 편집, 폴더 전체에서 글자 찾기
  • 포트 포워딩: 로컬(-L), 원격(-R), 동적 SOCKS5(-D)
  • 세션 히스토리: 앱을 종료할 때 열려 있던 탭으로 다시 돌아가기

자주 묻는 질문

SSH 접속

connection to … timed out이 나와요.

주소와 포트가 맞는지, 방화벽이나 VPN 때문에 막히지 않았는지 확인하세요.

authentication failed (password)가 나와요.

비밀번호를 확인하세요. 저장된 비밀번호가 바뀌었다면 세션 편집에서 새 비밀번호를 입력하고 저장하세요. 또는 Windows 자격 증명 관리자에서 WLT/ssh/로 시작하는 항목을 지우면 다음 접속 때 다시 묻습니다.

authentication failed (public key) / private key not found가 나와요.

개인 키 경로가 맞는지 확인하세요. 서버의 ~/.ssh/authorized_keys에 공개 키가 등록되어 있어야 합니다.

REMOTE HOST IDENTIFICATION HAS CHANGED! 경고가 나와요.

서버 키가 바뀌었습니다. 서버를 새로 설치한 것이 확실할 때만, 경고에 나온 줄을 WLT 앱 데이터 폴더의 known_hosts 파일에서 지우고 다시 접속하세요. 그렇지 않다면 서버 관리자에게 먼저 확인하세요.

한글이 깨져 보여요.

서버의 로케일이 UTF-8인지 확인하세요. locale 명령 결과에 UTF-8이 보여야 합니다.

파일 탐색기

탐색기 대상 목록에 서버가 없어요.

서버 탭이 연결된 상태(🟢)일 때만 목록에 나옵니다.

server refused SFTP가 나와요.

서버에서 SFTP가 꺼져 있습니다. 서버의 /etc/ssh/sshd_config에 Subsystem sftp … 줄이 있는지 서버 관리자에게 확인하세요.

서버 파일을 고치고 저장했는데 올라가지 않아요.

탐색기 아래 편집 중 목록에서 상태를 확인하세요. 업로드 실패라면 표시된 이유(권한 등)를 확인하고 다시 저장하세요. 목록에 파일이 없다면 연결이 끊겨 자동 업로드가 멈춘 상태이니 탐색기에서 파일을 다시 여세요.

Windows 탐색기에서 끌어다 놓았는데 아무 일도 없어요.

WLT의 탐색기 트리 위(폴더나 빈 곳)에 놓아야 합니다. 사이드바가 터미널 메뉴일 때는 탐색기 메뉴로 바꾼 뒤 놓으세요.

세션 히스토리 · 화면 · 로그

탭을 닫았는데 히스토리에 없어요.

기본 설정에서는 앱을 종료할 때 열려 있던 탭만 기록합니다. 직접 닫은 탭도 남기려면 설정 → 세션 히스토리 → 탭을 직접 닫을 때도 히스토리에 저장을 켜세요.

히스토리에서 복귀했는데 홈 폴더에서 시작해요.

셸이 현재 폴더를 알려 주지 않은 경우입니다. 설정 → 세션 히스토리의 셸 통합이 켜져 있는지 확인하세요. SSH 서버는 bash · zsh에서 자동으로 지원됩니다.

화면이 깨지거나 글자가 이상하게 그려져요.

설정에서 WebGL 렌더러를 끄고 다시 확인하세요.

로그 파일이 안 생겨요.

설정의 로그 저장을 켠 뒤 새로 열거나 다시 연결한 탭부터 기록됩니다. 터미널 첫 줄에 ● 로그 기록 중: 경로가 보이는지 확인하세요.

데이터와 제거

저장한 비밀번호를 지우고 싶어요.

앱에서 세션을 삭제하면 저장된 비밀번호도 함께 지워집니다. 세션은 두고 비밀번호만 지우려면 Windows 자격 증명 관리자 → Windows 자격 증명에서 WLT/ssh/로 시작하는 항목을 삭제하세요.

앱을 완전히 제거하려면 어떻게 하나요?

Windows 설정 → 앱 → 설치된 앱에서 WLT를 제거하세요. 세션 로그를 켰었다면 로그 폴더(기본값 문서\WLT Logs)도 직접 삭제하세요. 자세한 저장 위치는 개인정보처리방침에 있습니다.

제 정보가 어딘가로 전송되나요?

아니요. WLT는 사용자가 직접 접속한 서버와만 통신하며, 사용 통계나 개인정보를 수집하지 않습니다. → 개인정보처리방침

Frequently asked questions

SSH connections

I get connection to … timed out.

Check that the address and port are correct and that a firewall or VPN is not blocking the connection.

I get authentication failed (password).

Check your password. If a saved password has changed, enter the new one in the session editor and save. Or delete the entries starting with WLT/ssh/ in Windows Credential Manager, and WLT will ask again on the next connection.

I get authentication failed (public key) / private key not found.

Check the private key path. Your public key must be listed in ~/.ssh/authorized_keys on the server.

I see REMOTE HOST IDENTIFICATION HAS CHANGED!.

The server's key has changed. Only if you are sure the server was reinstalled, delete the line shown in the warning from the known_hosts file in WLT's app data folder and connect again. Otherwise, check with the server administrator first.

Non-English characters look broken.

Make sure the server locale is UTF-8. The output of the locale command should include UTF-8.

File explorer

My server is not in the explorer's target list.

A server appears only while its tab is connected (🟢).

I get server refused SFTP.

SFTP is disabled on the server. Ask the administrator to check that /etc/ssh/sshd_config contains a Subsystem sftp … line.

I edited and saved a server file, but it was not uploaded.

Check the 편집 중 (Editing) list at the bottom of the explorer. If it says 업로드 실패 (upload failed), fix the reason shown (permissions, etc.) and save again. If the file is not in the list, automatic upload stopped because the connection ended; open the file again from the explorer.

Nothing happens when I drag files from Windows File Explorer.

Drop them on WLT's explorer tree (on a folder or empty space). If the sidebar shows the terminal list, switch to the explorer first.

Session history, display and logs

A tab I closed is not in the history.

By default, only tabs open when you quit the app are recorded. To keep tabs you close yourself, turn on Settings → Session history → 탭을 직접 닫을 때도 히스토리에 저장 (save to history when closing a tab).

After restoring from history, the shell starts in the home folder.

The shell did not report its current folder. Make sure 셸 통합 (shell integration) is on in Settings → Session history. On SSH servers, bash and zsh are supported automatically.

The screen looks broken or text is drawn incorrectly.

Turn off WebGL 렌더러 (WebGL renderer) in Settings and check again.

No log files are created.

After turning on 로그 저장 (save logs) in Settings, logging starts with newly opened or reconnected tabs. Check that the first line of the terminal shows ● 로그 기록 중: … (logging to: path).

Data and uninstalling

How do I delete a saved password?

Deleting a session in the app also deletes its saved password. To remove only the password, open Windows Credential Manager → Windows Credentials and delete the entries starting with WLT/ssh/.

How do I completely remove the app?

Uninstall WLT from Windows Settings → Apps → Installed apps. If you used session logging, also delete the log folder (default Documents\WLT Logs). See the Privacy Policy for all storage locations.

Is any of my information sent anywhere?

No. WLT communicates only with servers you connect to and does not collect usage statistics or personal information. → Privacy Policy
